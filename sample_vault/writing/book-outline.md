# Book outline draft: MCP for normal people

The pitch: AI agents are much easier to explain with one good analogy.
An MCP server is the universal adapter plug between an assistant and the
things you actually use — files, notes, calendars, whatever.

## Chapter sketch

1. What problem MCP solves, in one paragraph.
2. Tools are just function calls with names and descriptions.
3. Safety is a design decision: vaults, allowlists, backups.
4. Build a tiny stdio server from scratch, standard library only.
5. Test it by hand in the Inspector before you trust it.

## Voice guidelines

- Plain English, step by step, never condescending.
- Every chapter ends with a "try this" from a real vault, like this one.
